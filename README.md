# Arabesque 🩰

PWA для юных гимнасток: домашние задания с тренировками, расписание зала и соревнований, чеклисты, награды и фото-отчёты для тренера.

**Прод:** https://arabesque.brainsome.app

## Возможности (v0.1)
- **Задания** — готовые комплексы и свои наборы из библиотеки (28 упражнений для 4–7 лет), плеер с таймером/счётчиком повторов, звуком и вибрацией.
- **Награды** — ⭐ за каждое упражнение, +3 за комплекс, +2 за фото; 9 наклеек за звёздочки, 8 значков (серии, первое фото, «сама собралась»…).
- **Расписание** — недельные тренировки и соревнования с обратным отсчётом.
- **Чеклисты** — «Взять с собой» (сбор сумки) и «Покупки» (нужно / куплено).
- **Тренер** — добавление и приглашение по коду, фото-отчёты с флагом «видно тренеру». Кабинет тренера (`/teacher`) — заглушка.
- **Ари** — персонаж-помощница (временный образ, проработаем отдельно).
- Офлайн-режим (service worker), установка на экран «Домой», тёмная тема.

Данные пока хранятся на устройстве (localStorage + IndexedDB для фото). Бэкенд нужен для кабинета тренера.

## Разработка
